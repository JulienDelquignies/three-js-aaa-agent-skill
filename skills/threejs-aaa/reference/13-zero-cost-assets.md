# Zero-Cost Pipeline (No Paid APIs)

**Target: full Claude Code, 0 surcharge beyond the Pro/Max plan, zero paid external API calls.**

and free/open local tools. Paid generators (Meshy/Tripo/Rodin/Blockade in `reference/10`, DeepMotion
in `reference/11`) are **opt-in only** — never on the default path.

## The principle

**Claude Code is the generator.** Its core strength — writing procedural geometry, TSL/GLSL shaders,
scene assembly, and asset-processing scripts — costs nothing beyond your plan and produces infinite,
seam-free, resolution-independent content. For the things code can't synthesize (a photoreal HDRI, a
scanned material, a rigged human), pull from **CC0 libraries with free APIs** or process with **free
local tools**. No credits, no keys, no per-asset billing.

Order of preference, cheapest first: **procedural → CC0 fetch → free local tool → free local open
model (if GPU) → (only if you choose) paid API.**

## Decision tree for any asset

```
Need an asset?
├─ Can it be generated by code? ──────────────▶ PROCEDURAL (free, best)
│   geometry, terrain, noise textures, materials, L-systems, dungeons, foliage,
│   greebles, particles, animated shaders → reference/03, 06, 07, 08 + procgen.mjs
├─ Is it a photoreal material / HDRI / scanned surface? ─▶ CC0 LIBRARY (free API)
│   Poly Haven, ambientCG → fetch-cc0.mjs
├─ Is it a game prop / kit / character mesh? ─▶ CC0 LIBRARY (free)
│   Kenney, Quaternius, Poly Haven models, Sketchfab (CC0 filter)
├─ Is it a rigged/animated humanoid? ─────────▶ FREE TOOLS
│   Mixamo (free rig+anim), AccuRIG (free), Ready Player Me (free avatars) → reference/05, 11
├─ Live face/body capture? ───────────────────▶ MediaPipe (free, in-browser) → reference/11
├─ Need post-processing (retopo/optimize/upscale/PBR maps)? ─▶ FREE LOCAL TOOLS
│   Blender headless, gltf-transform, Instant Meshes, xatlas, DeepBump, Real-ESRGAN, Rhubarb
└─ Still need bespoke AI generation AND have a GPU? ─▶ SELF-HOST an open model (free)
    TRELLIS / TripoSR / InstantMesh locally → reference/10
    (Only reach for a PAID API if none of the above fit AND you accept the cost.)
```

## Free CC0 asset libraries

All CC0 (public domain, no attribution, commercial-safe worldwide — EU included).

| Source | What | Free API (no key) |
|---|---|---|
| **Poly Haven** | HDRIs (true-HDR), PBR textures, models | `api.polyhaven.com` — used by `fetch-cc0.mjs` |
| **ambientCG** | 2000+ PBR materials, HDRIs, models | `ambientcg.com/api/v2/full_json?type=Material&include=downloadData` |
| **Kenney.nl** | huge CC0 game-asset kits (props, characters, UI, audio) | site download (no API); grab kits directly |
| **Quaternius** | CC0 low-poly model packs (nature, characters, dungeons) | site download |
| **Sketchfab** | huge model library — **filter to CC0/CC-BY** | API (free key) or manual; check license per model |
| **Mixamo** | free auto-rig + 2400 humanoid animations | free (Adobe account) — see `reference/05` |
| **Ready Player Me** | free rigged avatars (ARKit face + visemes) | free — see `reference/11` |
| **Anything World** | **creature/non-humanoid** auto-rig + animation → GLB/FBX | **free tier** (Individual, <$100K rev; attribution required) — REST API |
| **Rokoko** | video-to-motion mocap + ~150 commercial-usable clips | **free Starter tier** (FBX, unlimited text-to-motion; retargets to Mixamo) |

Prefer CC0 over CC-BY when you can, to avoid attribution bookkeeping. Poly Haven and ambientCG are
100% CC0.

## Per-asset-type zero-cost recipe

- **Geometry / props** → procedural (`procgen.mjs`, BufferGeometry, CSG, L-systems) or Kenney/Quaternius CC0 kits.
- **Terrain** → procedural noise + erosion (`reference/07`), textured with CC0 material via `fetch-cc0.mjs`.
- **Materials/textures** → procedural TSL noise (`reference/03`) for repeating/large surfaces; CC0 PBR
  sets from Poly Haven/ambientCG (`fetch-cc0.mjs`) for photoreal hero surfaces.
- **HDRI / lighting** → CC0 true-HDR from Poly Haven (`fetch-cc0.mjs --hdri`). Best IBL, free, real-HDR.
- **Characters** → CC0 mesh (Quaternius/Sketchfab-CC0) or Ready Player Me → **Mixamo/AccuRIG** free rig.
- **Animation** → free Mixamo clips; cleanup/authoring in Cascadeur free tier; live capture via MediaPipe.
- **Facial/lip-sync** → MediaPipe FaceLandmarker (live, free) or Rhubarb (offline, free) → morph targets.
- **Foliage/scatter** → procedural instancing + GPU grass (`reference/08`), no assets needed.
- **Optimization** → gltf-transform + KTX2 + Meshopt, all free (`reference/09`, `10`).

## The fetch-cc0 script

`scripts/fetch-cc0.mjs` — free CC0 HDRIs and full PBR texture sets from Poly Haven, no API key, zero deps.

```bash
# Browse
node ${CLAUDE_SKILL_DIR}/scripts/fetch-cc0.mjs --list hdris --search sunset
node ${CLAUDE_SKILL_DIR}/scripts/fetch-cc0.mjs --list textures --search rock

# Fetch a true-HDR environment for IBL
node ${CLAUDE_SKILL_DIR}/scripts/fetch-cc0.mjs --hdri kloofendal_48d_partly_cloudy --res 2k --out ./public/env.hdr

# Fetch a full PBR texture set (albedo/normal/roughness/ao/height, correct color spaces documented)
node ${CLAUDE_SKILL_DIR}/scripts/fetch-cc0.mjs --texture rock_boulder_dry --res 2k --out-dir ./public/textures/rock

# List a model's CC0 download URLs
node ${CLAUDE_SKILL_DIR}/scripts/fetch-cc0.mjs --model <model_id>
```

It prints the exact Three.js wire-up (with correct sRGB/linear color spaces). Everything downloaded is CC0.

## Self-hosted open models (free, needs a GPU)

If you want bespoke AI generation with **no API cost** and you have a GPU, run open models locally —
this is free (only your own hardware/electricity):
- **TripoSR** (~6 GB VRAM, MIT), **InstantMesh** (Apache), **TRELLIS** (MIT; vet the `nvdiffrast` dep),
  **SF3D** (UV+PBR, ≤$1M revenue), **StableMaterials** (tileable PBR), **Real-ESRGAN**, **DeepBump**.
- For an EU/commercial project, prefer MIT/Apache models; **avoid the Hunyuan3D family (EU-excluded
  license)** — see the licensing table in `reference/10`.
- No GPU? Stay on **procedural + CC0 + free local tools** — it covers the vast majority of a game.

**Bottom line:** a complete, good-looking Three.js game is fully achievable with **procedural code +
CC0 assets + free local tools**, entirely inside your Claude Code plan, with zero paid API calls.
